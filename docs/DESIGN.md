# Gradus 対位法ドリル — 設計の決定

設計の決定(理由つき)と、完了した段階を書く。設計が変わったときだけ更新する。
現状は `STATUS.md`、未完了の作業・未決・段階3の候補は `PLAN.md`。作業の決まりは `CLAUDE.md`。
段階2までの項目ごとの詳しい仕様・受け入れ条件・実装メモは、git の履歴(コミット `4a5ed23` の `docs/PLAN.md`)にある。

---

## 1. 目的と範囲

- フックス『Gradus ad Parnassum』(1725)の類別対位法(第1〜5類・2声)を、書く・聴く・判定を受ける・考え方を学ぶ、の4つで練習するブラウザアプリ。
- 利用者は日本語話者(大学で教える音楽家)。画面の文言はすべて日本語。
- 計画にない機能は足さない。新しい機能は、まず `PLAN.md` に載せ、仕様を決めてから作る。

## 2. 設計の決定

### 作り
- **ビルドなし、素のスクリプト**(`<script src>` で順に読む IIFE。フレームワーク・npm 依存なし)。
  理由: Claude上のページにも、リポジトリ直下をそのまま配信する PWA にも、同じファイルを置けるようにするため。
- **計算部(`engine.js`・`drills.js`・`lessons.js`)は DOM・localStorage・画面の状態に触れない。**
  理由: ブラウザ本体・Web Worker・Node(テスト)のどこでも同じに動かすため。
- **重い計算は Web Worker**(`task(type,args)`)。Worker が作れない環境では、本体スレッドで同じ関数を実行する。
  理由: 解答探索・定旋律生成・復習問題・ドリルの生成の間も、画面を固めないため。
  - ドリル・復習の問題作りは、新しい依頼が来たら古い依頼を Worker ごと打ち切る(2026-11-25)。理由: 続けて切り替えると、要らない計算が順番待ちになるため。
  - 解答探索の厳しい段階は、短い時間で乱数を変えてやり直す(2026-11-25)。理由: 深さ優先探索は、最初の選び方が悪いと制限時間まで抜け出せないため。
- **アプリ本体はリポジトリ直下**(旧1ファイル版は `docs/legacy/`)。
  理由: GitHub Pages はリポジトリ直下か `docs/` からしか配信できないため。

### 音楽データ
- **音は綴りで持つ: `{s, a}`**(`s` = オクターヴ×7+音名番号、`a` = −1/0/+1)。音程も綴りで判定する。
  理由: 増4度と減5度、C♯ と D♭ を区別するため。MIDI 番号の差では代用しない。
- **対旋律は「スロット」の並び**(`buildSlots`)。値は `cp["m:b"]` に保存する。
  理由: 類ごとに決まったリズム(第5類だけは小節ごとに型を選ぶ)を、同じ形で扱うため。
- **判定結果は `{id, lv, cols, t, x}`**。`id` は `RULES` のキーで、復習の集計と出題(`INJECT`)が依存する。

### 判定と採点
- **判定の基準(`levels`)は、指摘の段階(誤り/注意/無視)を置き換えるだけで、線引きは変えない。**
  理由: 教科書による細部の違いを設定で吸収しつつ、規則そのものは1つに保つため。
- **解答探索・復習・ドリル・「学ぶ」は、常にフックス厳格の基準で動く。**
  理由: 利用者がゆるい設定にしても、模範となる解答や問題が崩れないようにするため。
- **採点は罰点表**(Nancy Rogers, FSU の Species Counterpoint Grading Guidelines を土台に、3・2・1点)。**合格** = 書き終えていて誤りが0。2026-11-17 利用者が「A を土台」と決定。
  理由: 「100点−誤り10−注意3」は根拠が弱かったため。

### 楽譜と画面
- **音符・休符・タイ・音部記号は VexFlow 5.0.0 が置き、選択枠・色・音程の行などの重ね表示は app.js が座標 `geo` から描く。**
  理由: 浄書の質と8分音符への対応、リハモ道場との統一のため。
  - VexFlow が使えないときは手描き表示(`drawStaffLegacy`)に切り替える。この経路は、壊さない範囲で放置してよい。
- **声部ごとに1段**。音部記号は声域から選ぶ(加線の少ないほう)。
- **楽譜がはみ出すときは、画面の幅にかかわらず小節の縮小図を出す**(2026-11-25)。
  理由: 1280px でも11小節は収まらず、終止が見えにくかったため。
- **広い画面(幅921px以上)では、楽譜の大きさを、小節がスクロールなしで並ぶ大きさ(下限 0.5 倍)に合わせ、「拡大」はそれに掛ける**(2026-11-28 利用者「10小節程度ならスクロールなしで見えるように」)。縮めた分、小節番号・音程・進行の文字は読める大きさに保つ。2段の間は譜表の間隔4.4つ分(VexFlow の例は4つ分。このアプリの値。「学ぶ」も同じ)。
- **狭い画面(幅920px以下)では、拡大率の上限を130%にする**(2026-11-20 利用者)。
  理由: 160% では2段が画面の縦に収まらないため。保存した拡大率は残すので、広い画面では160%に戻る。

### 保存・配布・権利
- **保存は localStorage の `gradus-v3` に1つにまとめる。** 構造を変えるときは、移行処理と書き出し/読み込みも合わせる。
  - 規則 id を改めたとき(2026-11-28、段階3a: `antiparallel`→`contrary`、`leapBig`→`leap`、`range`→`ambitus`)は、`gradus-v2` を書き換えずに `gradus-v3` へ移した。古いキーを残すのは、古い版に戻しても設定が残るようにするため(D25)。
  - 書き込みは400msにまとめ、ページを閉じるときに書き切る。読み込んだデータは1項目ずつ検査し、壊れた項目だけを捨てる(2026-11-25)。
    理由: 1音ごとに全データ(解答 最大300件)を書いていたため。壊れた記録1件でアプリが止まらないようにするため。
- **オフライン用キャッシュは、同じサイトのファイルをすべてネットワーク優先にする**(2026-11-25)。
  理由: キャッシュ優先だと、番号を上げ忘れたときに新しい index.html と古い JS が組み合わさるため。
- **Claude上のページで使えない機能**(ダウンロード、MIDI、マイク、Service Worker、外部への fetch)は、隠すか代わりの手段を出す。
- **配布**
  - Claude上のページ(非公開)は、変更のたびに再公開する。
  - GitHub Pages での web 公開は、内容をもう少し作ってから(2026-11-20 利用者)。
- **著作権**
  - All rights reserved(著作権者 jun)。
  - 収める譜例は、保護期間の終わった出典から書き起こしたものか、このアプリの解答例だけ。
  - 「学ぶ」タブの模範例は、フックスの英訳『Practical Rules for Learning Composition』(IMSLP #370587)から書き起こした(`docs/FUX-EXAMPLES.md`)。

### 理論にかかわる決定
- **第5類の8分音符**: 2つ1組で弱い4分拍(第2・4拍)だけに置く。順次で入り、順次で出る。上行は注意、3組以上は注意。最初の小節と最後の2小節には置かない。
  理由: フックス/イェッペセンの扱いに従うため。
- **第5類の飾られた掛留の解決を許す**: 掛留の不協和と、2度下の解決音の間に、協和音を1つはさむ形。解決音は同じ小節の中に置く(2026-11-18 利用者)。
  理由: フックス自身の第5類の例(第9小節)がこの形のため。
- **「反行による連続5度・8度」は誤り**(罰点表で平行と同じ3点のため。2026-11-18)。
- **隠伏5度・8度は、並行で完全協和に入るものすべてを誤りとし、一律2点。** 出典は「上声が跳躍して入るとき」だけ2点としているが、判定の線引きは変えていない。
- **「開始は完全協和」は第1小節の音だけに当てる**(終止から書いたときの誤判定を防ぐため)。
- **判定の基準「ゆるめ」でも、音域の注意は残す**(2026-11-18 利用者)。
- **教科書別の判定の基準は未定。当面はフックス厳格・ゆるめの2つのまま**(2026-11-18 利用者)。
- **対斜は「注意」の規則にし、一言説明を出す**(2026-11-27 利用者。未実装、`PLAN.md` の旋律づくりの誘導で足す)。対斜は、声部をまたいで続く2音が、同じ音名で臨時記号だけ違うもの(定旋律の C の次に対旋律が C♯ など)。
  理由:
  - 声部の中の半音階的進行は誤りにしているので、声部をまたぐ同じ動きを黙って通すと扱いが食い違う。
  - 2声で一律に禁じるかは教科書で分かれる(フックスが主に問題にするのは三全音の関係)ので、合否は左右しない「注意」(1点)にする。
  - アプリの解答例はもともと対斜を作らない(2026-11-27 に、フックスと自動生成の定旋律から作った解答 1053 件で確かめて0件)。
- **頂点を定旋律と同じ小節に置くことは、規則にせず助言にとどめる**(2026-11-27 利用者)。
  理由: よく教えられる指針だが、フックスの規則にはないため。
