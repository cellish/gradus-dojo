# Gradus 対位法ドリル(gradus-dojo)

フックス『Gradus ad Parnassum』(1725)の類別対位法(第1〜5類・2声)を練習するWebアプリです。ホーム画面に追加するとアプリとして起動し、一度開いた後はオフラインでも動きます。

## 機能

- **学ぶ**:類ごとに、考え方の解説、フックスの模範例(注釈つき・再生)、悪い例と直し方、手順に分けて書く「書いてみる」。
- **練習**:第1類(1対1)から第5類(華麗)まで。五線に音を置くたびに規則を判定し、音程と進行を表示します。
  - 選んだ音に関わる指摘は五線のすぐ下に、全体の指摘は右側(スマホでは下)に出ます。
  - 平行・隠伏5度/8度は、問題の2音を破線で結んで示します。最高音には▼の印が付きます。
  - 判定は「その場で表示」と「答え合わせで表示」から選べます。後者は自分で考えてから確かめる練習向けです。
  - 「解答例と比べる」で、探索で作った解答例を自分の解答に重ねて表示し、聴き比べ・採用ができます。
  - 第4類はタイの入/切、第5類は小節ごとのリズムを、五線の下の編集欄で選びます。
- **楽譜の拡大**:操作バーの「拡大」で 100/130/160% を選べます。スマホなど幅の狭い画面では、選んでいる音(再生中は鳴っている音)が見える位置へ楽譜が自動で動き、上に全小節の縮小図が出ます(タップでその小節へ)。
- **判定の基準**:「第◯類の規則」の引き出しで、「フックス厳格」と「ゆるめ」を切り替えたり、規則ごとに誤り・注意・無視を選んだりできます。解答例と復習の問題は、いつもフックス厳格の基準で作ります。
- **定旋律**:フックスの6旋法の定旋律のほか、「新しい定旋律」で自動生成できます(第1〜5類・上下どちらでも解答が作れることを確認済みのものだけ)。「定旋律の管理…」から音名で入力することもできます。
- **復習**:保存した解答で誤りの多かった規則を集計し、その規則の誤りを1か所だけ含む問題を自動で作って出題します。
- **記録**:保存した解答の一覧、よく間違える規則、記録の書き出し・読み込み(バックアップや端末の移行に)。
- **MIDI鍵盤**:「MIDI鍵盤を使う」を押すと、鍵盤で弾いた音が選択中の位置に入り、次の位置へ進みます(下の「MIDI鍵盤について」)。

書きかけの解答・記録・作った定旋律は、すべてブラウザの localStorage に保存されます。以前の版で書いた解答はそのまま引き継がれます。

## ファイル構成

```
├── index.html              画面の骨組み
├── css/app.css             見た目
├── js/engine.js            判定・解答探索・定旋律生成などの計算部
├── js/score.js             楽譜の浄書(VexFlow)
├── js/worker.js            重い計算を裏で行う Web Worker
├── js/app.js               画面・操作・保存・音・MIDI
├── manifest.webmanifest    アプリ名・アイコン・起動方法の設定
├── sw.js                   オフライン動作のための service worker
├── icons/                  アイコン
├── vendor/                 VexFlow 5.0.0(楽譜フォント Bravura・Academico 入り)とライセンス文
│   └── dojo-shared/core/   道場シリーズ共通の書法の部品(音高・音程の計算)
├── THIRD_PARTY_NOTICES.md  同梱・利用している他者の著作物
├── LICENSE                 著作権表示
├── README.md               このファイル
├── CLAUDE.md, docs/        開発の手引きと作業計画(アプリの動作には不要)
└── test/, tools/           計算部のテストと確認用スクリプト(アプリの動作には不要)
```

楽譜の描画には VexFlow(MIT License)を同梱しています。外部に依存するのは本文用の Google Fonts だけで、オフラインで初めて開いた場合は端末の標準フォントで表示されます。

## 手元で試す

service worker と Web Worker は `file://` では動かないので、簡易サーバーを立てて開きます。

```sh
cd gradus-dojo
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

## GitHub Pages で公開する

1. リポジトリ `cellish/gradus-dojo` を公開(Public)にします(GitHub Pages を無料で使うには公開が必要です)。
2. リポジトリの「Settings」→「Pages」を開き、「Source」を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存します。
3. 1〜2分後、`https://cellish.github.io/gradus-dojo/` で公開されます。

パスはすべて相対指定なので、サブフォルダに置いてもそのまま動きます。

## 大学などのWebサーバーに置く場合

フォルダの中身を HTTPS で公開されている場所にそのまま置けば動きます。service worker は HTTPS でしか動かないので、http のみのサーバーではオフライン機能とインストールが無効になります。`.webmanifest` が `application/manifest+json` で配信されるとより確実です。

## ホーム画面に追加する

- **iPhone / iPad(Safari)**:共有ボタン →「ホーム画面に追加」
- **Android(Chrome)**:メニュー →「アプリをインストール」(または「ホーム画面に追加」)
- **Mac / Windows(Chrome・Edge)**:アドレスバー右端のインストールアイコン

## MIDI鍵盤について

- **使えるブラウザ**:Chrome・Edge(パソコン、Android)。Firefox はサイトの許可を求められます。Safari(iPhone・iPad・Mac)は Web MIDI に対応していないため使えず、ボタンも表示されません。
- **必要な条件**:HTTPS で公開したアプリ版か localhost で開いてください。Claude 上のページでは MIDI 機器へのアクセスが許可されません。
- **使い方**:鍵盤をつなぎ、「MIDI鍵盤を使う」を押してブラウザの許可を出します。一度許可すると、次に開いたときも自動でつながります。
- **音名の綴り**:白鍵は幹音、黒鍵は C♯・E♭・F♯・G♯・B♭ として入力します。

## 更新するとき

1. ファイルを書き換えます。
2. `sw.js` の先頭にある `const CACHE = 'gradus-v7';` の番号を上げます(`gradus-v8` など)。
3. 公開先にアップロードします。

利用者の端末では、次に開いたときに新しい版が読み込まれます。

## 保存について

解答と記録は利用者のブラウザ内にだけ保存され、サーバーには送られません。ブラウザのサイトデータを消すと記録も消えるので、「記録」タブの「ファイルに保存」で時々バックアップしてください。
